# 프리랜서 마케터 포트폴리오 웹사이트 — PRD v1.0

## 1. 제품 개요

### 1.1 배경 및 문제 정의

채용 담당자는 하루 평균 50~100개의 포트폴리오를 검토하며, 개별 포트폴리오에 할애하는 시간은 평균 **6~30초**에 불과하다. 이 짧은 시간 안에 "이 사람과 이야기해 보고 싶다"는 판단을 이끌어내야 한다. 기존 PDF 이력서나 템플릿 기반 포트폴리오는 다음과 같은 한계를 가진다:

- 정량적 성과가 텍스트 속에 묻혀 즉각적 인지가 어려움
- 프로젝트 맥락(문제 → 전략 → 실행 → 결과)이 선형적으로만 전달됨
- 마케터 고유의 역량(데이터 해석력, 크리에이티브 감각, 전략적 사고)을 동시에 증명하기 어려움

### 1.2 제품 목표

| 목표 | 측정 지표 | 목표값 |
|------|----------|--------|
| 첫인상에서 핵심 역량 전달 | 히어로 섹션 체류 시간 | ≥ 8초 |
| 프로젝트 상세 탐색 유도 | 프로젝트 카드 클릭률 | ≥ 35% |
| 연락 전환 | CTA 클릭률 (이메일/미팅 예약) | ≥ 12% |
| 기술적 완성도 | Lighthouse Performance 점수 | ≥ 95 |
| 접근성 | Lighthouse Accessibility 점수 | ≥ 90 |

### 1.3 타겟 사용자

**1차 사용자 — 채용 담당자 / 클라이언트**
- 대행사 또는 인하우스 마케팅 팀 리드
- 빠른 판단을 원하며, "숫자로 증명하는 마케터"를 선호
- 모바일로 먼저 확인하고, 관심이 생기면 데스크탑에서 상세 검토

**2차 사용자 — 포트폴리오 소유자 (프리랜서 마케터)**
- 콘텐츠를 직접 관리하고 업데이트할 수 있어야 함
- 기술 배경 없이도 프로젝트 추가/수정이 가능해야 함

## 2. 정보 구조 (Information Architecture)

```
[Landing / Hero]
  │
  ├── Impact Dashboard (핵심 성과 숫자 3~4개)
  │
  ├── About (전략적 포지셔닝 + 차별점)
  │
  ├── Projects (케이스 스터디 그리드)
  │     ├── Project Detail Modal/Page
  │     │     ├── Challenge → Strategy → Execution → Result
  │     │     ├── 데이터 시각화 (Before/After 차트)
  │     │     └── 클라이언트 추천사
  │     └── 필터 (카테고리별: 퍼포먼스 / 브랜딩 / 콘텐츠 / 그로스)
  │
  ├── Skills & Tools (기술 스택 시각화)
  │
  ├── Testimonials (추천사 하이라이트)
  │
  └── Contact (CTA: 이메일 / 캘린더 예약 / 이력서 다운로드)
```

## 3. 핵심 기능 상세

### 3.1 히어로 섹션 — "30초 엘리베이터 피치"

**목적:** 페이지 진입 즉시 "누구인지 + 무엇을 잘하는지 + 왜 나를 뽑아야 하는지"를 전달

**구성 요소:**
- 헤드라인: 포지셔닝 한 줄 (예: "데이터로 증명하는 그로스 마케터")
- 서브 헤드라인: 핵심 경력 요약 (예: "7년간 B2B SaaS 스타트업에서 MAU 300% 성장을 만든 마케터")
- 프로필 사진: 전문적이면서도 친근한 톤
- CTA 버튼 2개: "프로젝트 보기" (스크롤 이동) + "미팅 잡기" (Calendly 연동)

**인터랙션:**
- 진입 시 텍스트 타이핑 애니메이션 (Framer Motion, 500ms 딜레이 후 시작)
- 스크롤 시 프로필 사진이 부드럽게 패럴랙스 효과로 후퇴
- 배경에 미묘한 그래디언트 애니메이션 (브랜드 컬러 기반)

### 3.2 Impact Dashboard — "숫자로 말하기"

**목적:** 채용 담당자가 가장 먼저 보는 정량적 증거

**구성 요소:**
- 3~4개의 핵심 지표 카드
- 각 카드: 숫자 (카운트업 애니메이션) + 짧은 설명 + 관련 프로젝트 링크
- 예시:
  - `+320%` MAU 성장률 (B2B SaaS)
  - `₩2.4억` 연간 광고 예산 운용
  - `47%` 전환율 개선 (랜딩페이지 최적화)
  - `12개` 브랜드 마케팅 프로젝트 수행

**인터랙션:**
- Intersection Observer로 뷰포트 진입 시 카운트업 트리거
- 호버 시 해당 성과의 맥락을 보여주는 툴팁
- 카드 클릭 시 관련 프로젝트로 스크롤 이동

### 3.3 프로젝트 갤러리 — "케이스 스터디 중심"

**목적:** 프로젝트의 사고 과정과 실행력을 구조화하여 보여줌

**카드 그리드:**
- 카테고리 필터 탭: 전체 / 퍼포먼스 마케팅 / 브랜딩 / 콘텐츠 / 그로스해킹
- 카드 구성: 썸네일 + 프로젝트명 + 한 줄 요약 + 핵심 성과 수치 뱃지
- 정렬: 임팩트 순 (기본) / 최신순

**프로젝트 상세 페이지 (모달 또는 별도 라우트):**

```
┌─────────────────────────────────────────┐
│  프로젝트 히어로 이미지                    │
├─────────────────────────────────────────┤
│  [Challenge]  [Strategy]  [Execution]  [Result]  ← 탭 네비게이션
├─────────────────────────────────────────┤
│  Challenge:                              │
│  "기존 랜딩페이지 전환율 2.3%로 업계     │
│   평균(4.1%) 대비 크게 낮았음"           │
│                                          │
│  Strategy:                               │
│  - 히트맵 분석 → 이탈 구간 3곳 식별      │
│  - A/B 테스트 설계 (4가지 변형)          │
│  - 카피라이팅 전면 재설계                 │
│                                          │
│  Result:                                 │
│  ┌──────────────────────┐               │
│  │ Before: 2.3%  ──────▶ After: 4.7%   │
│  │ [인터랙티브 차트]     │               │
│  └──────────────────────┘               │
│                                          │
│  💬 클라이언트 추천사                     │
│  "김 마케터 덕분에 전환율이..."           │
└─────────────────────────────────────────┘
```

### 3.4 Skills & Tools — "역량 시각화"

**목적:** 보유 기술과 툴 숙련도를 직관적으로 전달

**구성:**
- 카테고리별 그룹핑: 광고 플랫폼 / 분석 도구 / 디자인 / 자동화
- 각 스킬: 아이콘 + 이름 + 숙련도 바 (또는 연차 표시)
- 호버 시 해당 스킬을 활용한 대표 프로젝트 연결

### 3.5 Contact 섹션 — "행동 유도"

**구성:**
- 이메일 복사 버튼 (클릭 시 클립보드 복사 + 토스트 알림)
- Calendly 임베드 또는 외부 링크 (30분 커피챗 예약)
- 이력서 PDF 다운로드 버튼
- LinkedIn / GitHub / Behance 소셜 링크

## 4. 기술 아키텍처

### 4.1 기술 스택 선정 근거

| 레이어 | 선택 | 근거 |
|--------|------|------|
| 프레임워크 | **Next.js 14 (App Router)** | SSG로 빠른 초기 로드, SEO 최적화, 이미지 최적화 내장 |
| 스타일링 | **Tailwind CSS + Framer Motion** | 빠른 개발 속도, 일관된 디자인 시스템, 선언적 애니메이션 |
| CMS | **Notion API 또는 MDX** | 마케터가 직접 콘텐츠 관리 가능, 별도 백엔드 불필요 |
| 호스팅 | **Vercel** | Next.js 네이티브 지원, 글로벌 CDN, 무료 티어 충분 |
| 분석 | **Vercel Analytics + GA4** | 방문자 행동 추적, 전환 퍼널 분석 |
| 폼 처리 | **Resend (이메일 API)** | 서버리스 환경에서 간편한 이메일 발송 |

### 4.2 프로젝트 구조

```
src/
├── app/
│   ├── layout.tsx          # 글로벌 레이아웃, 폰트, 메타데이터
│   ├── page.tsx            # 메인 랜딩 (SSG)
│   ├── projects/
│   │   ├── page.tsx        # 프로젝트 목록
│   │   └── [slug]/
│   │       └── page.tsx    # 프로젝트 상세 (동적 라우트, SSG)
│   └── api/
│       └── contact/
│           └── route.ts    # 문의 이메일 발송 API
├── components/
│   ├── hero/
│   ├── impact-dashboard/
│   ├── project-card/
│   ├── project-detail/
│   ├── skills/
│   ├── testimonials/
│   └── contact/
├── content/
│   └── projects/           # MDX 파일 또는 Notion 연동 데이터
├── lib/
│   ├── notion.ts           # Notion API 클라이언트 (선택)
│   └── animations.ts       # Framer Motion 공통 변형
└── styles/
    └── globals.css          # Tailwind 설정 + CSS 변수
```

### 4.3 성능 최적화 전략

- **이미지:** Next/Image의 자동 WebP/AVIF 변환, blur placeholder, lazy loading
- **폰트:** `next/font`로 Pretendard 셀프 호스팅, `font-display: swap`
- **번들:** 컴포넌트 단위 동적 임포트, Framer Motion의 `LazyMotion` 사용
- **렌더링:** 모든 페이지 SSG (빌드 시 HTML 생성), ISR로 콘텐츠 업데이트 반영
- **코어 웹 바이탈 목표:** LCP < 1.5s, FID < 50ms, CLS < 0.05

### 4.4 SEO 전략

- 시맨틱 HTML (`<article>`, `<section>`, `<nav>`)
- Open Graph + Twitter Card 메타 태그 (프로젝트별 동적 생성)
- JSON-LD 구조화 데이터 (`Person`, `ProfilePage`, `CreativeWork`)
- `robots.txt` + `sitemap.xml` 자동 생성
- 타겟 키워드 설계: "프리랜서 마케터 포트폴리오", "그로스 마케터", "퍼포먼스 마케팅 전문가"

## 5. 디자인 시스템

### 5.1 디자인 원칙

1. **임팩트 우선:** 숫자와 성과가 시각적으로 가장 먼저 눈에 들어와야 한다
2. **여백의 미:** 정보 밀도를 낮추고, 핵심 메시지에 시선을 집중시킨다
3. **일관된 브랜드:** 포트폴리오 자체가 마케터의 브랜딩 역량을 증명한다

### 5.2 컬러 시스템

```
Primary:     #1A1A2E (딥 네이비) — 신뢰감, 전문성
Accent:      #E94560 (코랄 레드) — CTA, 강조, 성과 수치
Surface:     #F8F9FA (라이트 그레이) — 배경
Text:        #16213E (다크 블루) — 본문
Muted:       #94A3B8 (슬레이트) — 부가 정보
```

### 5.3 타이포그래피

```
Display:    Pretendard Bold 48px / line-height 1.2  — 히어로 헤드라인
Heading:    Pretendard SemiBold 28px / 1.3           — 섹션 타이틀
Subhead:    Pretendard Medium 20px / 1.4             — 카드 타이틀
Body:       Pretendard Regular 16px / 1.6            — 본문
Caption:    Pretendard Regular 14px / 1.5            — 부가 정보
```

### 5.4 반응형 브레이크포인트

```
Mobile:     < 640px   — 1컬럼, 터치 최적화, 햄버거 메뉴
Tablet:     640~1024px — 2컬럼 그리드
Desktop:    > 1024px   — 3컬럼 그리드, 사이드 네비게이션 가능
```

## 6. 사용자 시나리오

### 시나리오 A: 채용 담당자의 30초 탐색

```
0s   — 페이지 로드 → 히어로 섹션 노출
3s   — 헤드라인 + 서브 헤드라인 읽음 → "어떤 마케터인지" 파악
8s   — 스크롤 → Impact Dashboard 진입 → 카운트업 애니메이션 시작
15s  — 핵심 수치 3~4개 확인 → "성과를 내는 사람" 인지
20s  — 프로젝트 카드 그리드 스캔 → 관심 있는 프로젝트 1개 클릭
25s  — 프로젝트 상세 훑어보기 → Challenge-Result 확인
30s  — "이 사람과 대화해 보고 싶다" → CTA 클릭 or 북마크
```

### 시나리오 B: 관심 있는 클라이언트의 심층 탐색

```
1단계 — 히어로 → About 섹션에서 마케터의 철학/관점 확인
2단계 — 프로젝트 2~3개를 상세하게 읽으며 사고방식 평가
3단계 — Skills 섹션에서 자사 도구와의 호환성 확인
4단계 — 추천사 읽으며 협업 스타일 파악
5단계 — Calendly로 30분 미팅 예약
```

## 7. 구현 로드맵

### Phase 1 — MVP (2주)
- 히어로 섹션 + Impact Dashboard
- 프로젝트 카드 그리드 (3~4개 케이스 스터디)
- 프로젝트 상세 페이지 (MDX 기반)
- Contact 섹션 (이메일 + 이력서 다운로드)
- 모바일 반응형
- Vercel 배포

### Phase 2 — 고도화 (1주)
- Framer Motion 애니메이션 전체 적용
- Notion CMS 연동 (콘텐츠 자체 관리)
- GA4 + 전환 이벤트 트래킹 설정
- Open Graph 이미지 동적 생성
- 다크 모드 지원

### Phase 3 — 확장 (선택)
- 블로그 섹션 (마케팅 인사이트 → SEO 유입)
- 뉴스레터 구독 폼 (리드 수집)
- 다국어 지원 (한/영)
- A/B 테스트 (히어로 카피, CTA 문구)

| 지표 | 측정 도구 | 리뷰 주기 |
|------|----------|----------|
| 페이지 로드 시간 (LCP) | Vercel Speed Insights | 배포 시 |
| 방문자 수 / 이탈률 | GA4 | 주간 |
| 프로젝트 클릭률 | GA4 이벤트 | 주간 |
| CTA 전환률 | GA4 전환 목표 | 주간 |
| Lighthouse 점수 | CI/CD 파이프라인 | 배포 시 |
| 실제 미팅 전환 | Calendly + 수동 트래킹 | 월간 |
